WAF Lab - Test Website

This small site is protected by Apache + ModSecurity + OWASP Core Rule Set. It exists only so the firewall has something to protect during the assignment.

  • search.php - reflects the q parameter (XSS test target)
  • login.php - login form (SQL injection test target)
  • view.php - takes a page parameter (path traversal test target)
  • ping.php - takes a host parameter (command injection test target)

None of these pages touch a real database, the filesystem or a shell. They only echo input back, so the lab is safe to run.
